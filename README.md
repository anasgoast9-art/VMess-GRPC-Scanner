# VMess gRPC Scanner

هذا المشروع يعمل عبر GitHub Actions ويجمع روابط `vmess://` من ملفات نصية عامة تضيفها إلى `sources.txt`، ثم يحتفظ فقط بالروابط التي يوضح إعدادها أن `net` يساوي `grpc`.

## الإعداد

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع جميع ملفات هذا المشروع مع الحفاظ على المسارات.
3. افتح `sources.txt` وأضف روابط RAW مباشرة، رابطًا واحدًا في كل سطر.
4. من تبويب **Actions** شغّل **Scan VMess gRPC sources** عبر **Run workflow**.
5. بعد انتهاء التشغيل افتح نتيجة التشغيل ثم نزّل ملف `vmess-grpc-results` من قسم **Artifacts**.

## التشغيل التلقائي

ملف GitHub Actions مضبوط للتشغيل مرة كل ساعة، ويمكنك أيضًا تشغيله يدويًا. قد يؤخر GitHub تشغيل المهام المجدولة.

## ملاحظات مهمة

- لا يتصفح هذا المشروع GitHub عشوائيًا ولا يتجاوز قيود الوصول؛ بل يقرأ روابط RAW التي تضيفها أنت.
- فحص TCP يقيس إمكانية فتح اتصال TCP والكمون التقريبي فقط. لا يثبت أن مصادقة VMess أو TLS أو gRPC تعمل، ولا يقيس سرعة الإنترنت الفعلية.
- ترتيب الدول يعتمد على خدمة تحديد موقع IP وقد يظهر `Unknown` أو يتعذر بسبب حدود الخدمة.
- السيرفرات العامة قد تتوقف أو تكون غير موثوقة. لا تمرر بيانات حساسة عبر سيرفر مجهول.
- لا تضع رموز وصول أو أسرارًا أو بيانات شخصية داخل `sources.txt`.
